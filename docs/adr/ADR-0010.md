# ADR-0010: Rune reproducible builds

Status: Accepted for the prototype.

## Context

Patch Cage must make a reviewable change-safety decision without hiding missing evidence or coupling authorization to free-form model output.

## Decision

Rune reproducible builds is implemented as an explicit typed boundary with a caller, failure path, telemetry and acceptance evidence. It participates in the primary journey and is independently testable.

## Consequences

The boundary adds operational cost but makes denial, retry, provenance and ablation measurable. A missing receipt forces abstention.
