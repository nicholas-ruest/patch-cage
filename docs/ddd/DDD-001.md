# DDD-001: Assessment aggregate

## Language

The ubiquitous terms are assessment, patch, finding, claim, receipt, abstention, decision, effect and timeline.

## Model

Assessment aggregate owns a typed invariant, emits domain events, and never mutates another context's state directly. Commands are idempotent; policy denial emits a decision event but no release effect.

## Boundaries and failures

Inputs are validated at the boundary. Dependency failure yields a retryable status; contradictory evidence yields abstention. The application layer translates events for the API and audit view.
